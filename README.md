# 📊 Python Data Analysis – Assignment 2
## Data Visualization using Matplotlib, Pandas & Seaborn

### 📌 Project Overview

This project focuses on **Data Visualization using Python** as part of Python Data Analysis Assignment 2.

The project uses the Seaborn Taxis dataset to explore taxi trip information and represent data through different types of visualizations.

The main objective is to understand data patterns, distributions, comparisons, and relationships using Python visualization libraries.

### 🎯 Objectives

- Load and explore the Taxis dataset.
- Identify and handle missing values.
- Perform data visualization using Matplotlib and Pandas.
- Create statistical visualizations using Seaborn.
- Understand patterns and relationships in the dataset.
- Improve practical knowledge of Python Data Analysis.

### 🛠️ Technologies & Libraries Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn
- NumPy

### 📂 Dataset Information

**Dataset:** Taxis Dataset (Seaborn Built-in Dataset)

The dataset contains information about taxi trips, including:

- Pickup and drop-off details
- Trip distance
- Fare amount
- Tip amount
- Payment method
- Pickup borough and zone

### 📈 Visualizations Performed

#### 1. Matplotlib & Pandas

1. Line Chart
2. Bar Chart
3. Pie Chart
4. Histogram
5. Box Plot

#### 2. Seaborn

6. Count Plot
7. Scatter Plot
8. Heatmap
9. Pair Plot
10. Violin Plot

### ⚙️ Data Preprocessing

- Checked missing values.
- Handled missing values using suitable techniques.
- Used median for numerical columns.
- Used mode for categorical columns.
- Prepared the dataset for visualization.

### 🚀 How to Run This Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Python-Data-Visualization
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `Data Visualization.ipynb` and run all cells.
